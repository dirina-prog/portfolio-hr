# HR work samples — Irina Derevianchenko

Frameworks and toolkits I built myself, using AI as a drafting partner.

**What these are:** work samples produced as practice work and assignments —
structures I designed, not systems I have rolled out inside an employer. Company names have been removed; only the industry shape is kept.

**What they are not:** they are not evidence of implementation. Where I have
worked with competency frameworks and 360-degree feedback in a live performance
cycle, I used the employer's existing instruments. These samples show how I
think about the design.

## A note on the targets

Numeric targets in `kpi-by-department.xlsx` are **indicative placeholders**. They
define the shape of a metric, not the number. A target only becomes real once it
is set with the department head against team size, tooling and a measured
baseline. Presented any other way, a number like "≥ 80 story points per sprint"
is a guess with a decimal point.

The same applies to the competency levels: the behavioural indicators are the
substance, the labels are conventions to be agreed with the business.
